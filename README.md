# ggbIO
https://github.com/Zodiac-Innovations/ggbIO
Cross-platform framework for turn-based board, puzzle, and strategy games.

This public package currently provides only the application startup scaffold.
The Apple host displays no game content.

All framework development for the foreseeable future takes place in
[ggbIOExperiment](https://github.com/Zodiac-Innovations/ggbIOExperiment).
Game and puzzle lifecycle hooks, image data, vectors, colors, and materials
are available there while the public package remains minimal.
